Один полный прогон на Xiaomi Mi Box S 4K, Android 14, Lampa 1.13.6 (586), с физическим пультом должен включать:

1. Установку финального кандидата пользователем и перезапуск Lampa; проверку названия версии.
2. Проверку рабочего адреса MiniDLNA.
3. Проверку недоступного адреса с фиксацией ошибки.
4. Восстановление рабочего адреса, повторную успешную проверку и открытие каталога.
5. Навигацию по папкам с восстановлением фокуса, Back из корня в настройки с сохранением панели.
6. Воспроизведение A во внешнем Android-плеере, возврат по Back в исходную папку с фокусом, отсутствие самозапуска и запуск B только после нового явного выбора и OK.
7. Проверки всех дополнительных функций, которые будут согласованы для финальной сборки.
