## Подготовка к дополнительной приёмке

- Записать SHA-256 установленного `plugin.js`, модель устройства, версию Android, версию и источник Lampa, выбранный плеер и MediaServer.
- Удалить старую ссылку на DLNA Bridge из расширений, полностью перезапустить Lampa, установить тестовый файл и снова перезапустить. В настройках должен появиться один компонент с меткой `1.0.2-rc.1`.
- Выполнить основной сценарий в MEmu, затем повторить на Xiaomi Mi Box S 4K с физическим пультом.

## Дополнительные проверки Renderer

- С ручным URL проверить разбор описания, доступность AVTransport, запуск, Pause, Play, Seek и Stop там, где устройство поддерживает эти функции. Проверить естественное завершение и смену активного устройства во время опроса.
- Запустить SSDP при доступном UDP API и при его отсутствии. Проверить сообщение об отсутствии транспорта или таймауте, повторный поиск и доступность ручного URL.
- Вернуть локальный плеер, перезапустить Lampa с сохранённым URL и повторить локальный запуск.

Стабильный выпуск требует записанного результата всех обязательных строк на физическом Android TV. Событие `external` в журнале дополняет наблюдение фактического воспроизведения на экране.
