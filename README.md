# DLNA Bridge для Lampa Android TV

Плагин открывает каталог DLNA MediaServer в Lampa и воспроизводит выбранные файлы в штатном плеере. Сервер можно добавить вручную по адресу. Поддержка внешнего MediaRenderer доступна в кандидате и ожидает ручной проверки.

## Установка

**1.0.2-rc.1** — тестовая версия. Для ранее принятой версии доступна [сборка 0.6.8](https://nosferato497-ship-it.github.io/dlna-plugin/v068/plugin.js).

1. В Lampa откройте **Настройки → Расширения → Добавить плагин**.
2. Укажите [установочный URL 1.0.2-rc.1](https://nosferato497-ship-it.github.io/dlna-plugin/v102-rc1/plugin.js). При переходе с другой версии удалите её ссылку из расширений и полностью перезапустите Lampa перед установкой.
3. Перезапустите Lampa, откройте **DLNA Bridge**, укажите адрес вашего DLNA-сервера и откройте каталог.

## Что проверено

25 ноября 2026 года пользователь подтвердил 16 сценариев на Xiaomi Mi TV Stick с Lampa и Netcraze Ultra MiniDLNA, включая MKV, навигацию, возврат из плеера и повторный запуск. SSDP на испытанной сборке заблокирован: доступный UDP API не подтверждён. Статусы остальных сценариев приведены в [матрице совместимости](docs/compatibility.md).
